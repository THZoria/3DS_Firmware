# 3DS_Firmware
Hello welcome to this 3ds preservation project my goal here is to preserve Ninendo 3ds firmware in it's entirety new stuff will be added as i have infomation for it a couple of things are missing as the infomation is missing for that firmware so please be patient as i am working to upload this i am working on my own to upload this stuff and update new releases 
# Instructions for Pre setup DO NOT SKIP 

Please have a NAND backup of your console BEFORE you even use this DO NOT Proceed if you have not made one YOU HAVEE BEEN WARNED 

Step one Open GM9 by pressing start on boot 

Step two press Home Scripts GM9mega scripts Backup options Sysnand backup 

Step 3 do the prompts on screen and let it load

Step 4 once this is completed then we can proceed with the actual installation\downgrading of your console

Step 5 download 
https://github.com/profi200/sysUpdater
then put the Sysupdater cia in the cias folder on the root of your sd card you can use FBI or Gm9 to install the cia to your SD card 
once you have done this correctly you should be able to boot the console and a new application will apppear on the home menu called sysupdater you will need this for the updating\downgrading step later on

Step 6 Delete pretendo if your going below 11x it will crash if you don't so maake sure if your using a service like Pretendo REMOVE it before proceeding as Luma will try to load the patches and it crashes as a result of this


# Updating a existing Firmware 
extract the file you downloaded from the release page onto the root of your sd card you should see a updates folder 
this will be important for sysupdater once you done this and you have made a nand backup you should be able to launch the application you installed with GM9 or FBI from the home menu of your current firmware you want to update from it for updating select the update option to update from the current firmware to the one you placed onto the root of your sd once the installation is done assumeing you have done everything else correctly and you got no errors it will reboot the console with the new firmware applied replacing the old one in it's place 

# Downgrading a Firmware
same steps as previously mentioned but you want to downbload a lower version then the one you have currently so let's say as a example you want to download 1.0 from 11.17.0-50E you want to download 1.0 from the releases and place the updates folder onto the root of your SD important once the installation finishes for versions that are this low you want to boot back into gm9 press home Gm9 mega scripts scripts from plailect's Guide select remove extradata this will remove the home mennu extra data as not doing this will cause the 3ds not to boot showing the back lights only 
also make sure that Luma3ds's patches are turned off by holding Select at boot and unchecking all the options that are enabled like 

"enable Loading external firms and modules"

"enable Game patching"

if you don't do this it can crash while using the firmware so please do this 

# After finishing for people who peformed downgrades 
I'd recommend factory wiping the 3ds to clear any possible bad and left over tickets from the previous firmware this can help improve stability and stop bugs from occuring as a result of this
